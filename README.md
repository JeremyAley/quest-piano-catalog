# Quest Piano Trainer song catalog

The official song catalog for Quest Piano Trainer, a mixed-reality piano trainer for Meta Quest 3. The app reads `catalog.json` from this repository and downloads each song's difficulty levels when they are first played.

- `catalog.json`: the song list (catalog format version 1), easiest first. Per song: a short display title (and `full_title` when it differs), composer, licence, attribution, source, difficulty and how widely known it is (`known`, 0-1); per difficulty level: its file, SHA-256, note count and difficulty number.
- `songs/<id>/level<N>.mid`: app-ready MIDI, one file per difficulty level (1 Melody, 2 Melody + bass, 3 Simplified, 4 Full). Track 1 is the right hand, track 2 the left. Each note-on is preceded by a text event `f1`-`f5` with a finger (1 thumb .. 5 little); levels with fingers have `"fingering": true`. Where the source score prints a finger (MusicXML scores, Mutopia's LilyPond sources), a text event `printed` comes just before that finger's text; the other fingers are suggestions from the pipeline's own fingering model.
- `songs/<id>/level<N>.sheet.json` and `level<N>-p<K>.png`: sheet music for a level, engraved from the same notes (Verovio), as page images plus a map from each bar to its page and time. Pages are 2-bit greyscale with one meaning per level (0 notes and text, 85 staff and bar lines, 170 the notes' anti-aliased edge, 255 paper), so the app can print the staff in a lighter tone. Page 1 has a title block (title, composer, level, and the tempo marking the source prints or else a metronome mark) and every page a page number; the text is set in Liberation Serif (SIL Open Font License). A level has a `sheet` entry in `catalog.json` when it has sheet music.

222 pieces (classical, ragtime, Christmas carols, hymns and marches) from [piano-midi.de](http://www.piano-midi.de), the [Mutopia Project](https://www.mutopiaproject.org) and [PDMX](https://zenodo.org/records/15571083), plus our own arrangements of public-domain carols: public domain, CC0, CC BY or CC BY-SA. The files are generated by the Quest Piano Trainer content pipeline. Licences and credits are in [LICENSES.md](LICENSES.md) and, per song, in `catalog.json`.

This repository is published as a single commit each time the catalog is rebuilt, so cloning it never downloads old versions of the files.
